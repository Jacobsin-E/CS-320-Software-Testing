# CS-320 Software Testing, Automation, and Quality Assurance

This repository contains portfolio artifacts demonstrating my ability to create unit tests, analyze software testing approaches, and apply appropriate testing strategies to meet strict client requirements. The included Java files showcase a Contact management service, alongside the JUnit 5 test scripts used to validate its logic. A comprehensive Summary and Reflections report is also included to detail my testing methodology.

## Portfolio Reflection

**How can I ensure that my code, program, or software is functional and secure?**
To ensure my software is functional and secure, I rely on a combination of automated testing and rigorous manual validation. My approach is to design specific tests that intentionally push the boundaries of the software. Whether using automated test scripts or manually entering improper inputs, my ultimate objective as a developer is to try and break the code before it reaches production. Similar to troubleshooting complex hardware systems, finding the failure points early guarantees the final product can withstand unexpected stress and remain secure.

**How do I interpret user needs and incorporate them into a program?**
Interpreting user needs relies entirely on establishing a clear iterative feedback loop with stakeholders. The process begins by gathering detailed information about their specific objectives. From there, I draft formal requirements and present them back to the stakeholders for review. This ensures we are completely aligned on the expected functionality. Only after receiving a definitive approval on these requirements do I begin the coding process, guaranteeing that the final deliverable matches the client's exact vision.

**How do I approach designing software?**
I approach software design by strictly adhering to the phases of the Software Development Life Cycle (SDLC). The foundation of this approach is solidifying the requirements with stakeholders first so the project has a clear roadmap. As a developer, I also make sure to offer my technical expertise and recommendations to help optimize the client's requests. Ultimately, my design goal is to create intuitive, bug-free software that provides the user with quick, snappy feedback, ensuring a highly responsive experience without compromising on security.
